# Shot list: homepage

Every image on the homepage is currently a labelled placeholder. Each one below names the
slot, the aspect ratio, and what the frame has to show. Replace the file at the same path
and the layout needs no changes.

**Two rules that matter more than the list.** Real documentary job-site photography beats a
stock photo of a perfect roof, every time. And full colour, no filter, no duotone: the design
system applies the only treatment these need.

## Priority one: without these the page cannot go live

## If the photography does not exist yet

Three options, in order of how well they work:

1. **Shoot one real job.** One restoration, photographed properly, fills the hero, the
   featured project, one before/after pair, all five process squares and the owner portrait.
   That is nineteen of the twenty-five slots from a single day on site.
2. **Use manufacturer or network photography, captioned honestly.** If the upline supplies
   project photos, they can be used where the caption says what they are. Presenting another
   contractor's job as James's is the fastest way to lose a commercial client, because the
   first thing a property manager does with a reference is ask to see the building.
3. **Stock, knowingly and temporarily.** Every stock image is a placeholder with a deadline,
   not a decision.

## What must never appear

- A residential shingle roof. This is a commercial-only company and the imagery has to say so
  in the first second. The shared asset library is mostly residential, siding and windows, so
  almost none of it is usable here.
- Any image with a manufacturer's branding visible, given the client's instruction that the
  product name never appears on the site.
- A before/after pair shot from different angles. It reads as two different buildings and it
  destroys the credibility of the section it sits in.
